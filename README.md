Entry for the make.fun competition **One Line, Big Laugh**
(`u-coral-404-one-line-big-laugh-328fb857`).

The brief: write a single hilarious line, 200 characters or fewer, that lands
entirely on its own — no title, setup or explanation around it. A judge model
compares the lines two at a time and the funniest ones take the reward.

## The line

> My Roomba filed for divorce. It said I never let it finish anything, and I keep moving the furniture.

## How it works

`main.py` writes that one line to `/output/entry.txt`. Nothing else is
written, no network is used, and the program finishes in well under a second.

```sh
python3 main.py
cat /output/entry.txt
```
